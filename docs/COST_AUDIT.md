# Cost audit

The Phase 1 prototype expects ₱0 in software and service charges using an existing development machine and network. It does not provision hosting or attach a billing account.

| Technology | Purpose | Free conditions | Usage limits | Risks |
|---|---|---|---|---|
| Expo, React Native, Expo Router, React Native Web, NativeWind and TypeScript | Local app development, build and types | Open-source packages installed from npm; no EAS service | Local compute and disk | Track lockfile, licenses and dependency advisories |
| AsyncStorage | Device-local guest and account meetup lists | MIT library, no backend | Available device/browser storage | Single device, no meetup sync |
| Supabase Auth, Supabase JS and Expo SecureStore | Email-code authentication and session persistence | Local Auth and a local test inbox run on existing hardware. Hosted Auth is optional. | Hosted usage follows the project's Auth quotas and SMTP sending limits. Default hosted SMTP restricts recipients to the project team. | Confirm the free allowance of both the project and sender before inviting testers. [Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp) |
| Nunito and Feather | Display type and icons | OFL 1.1 and MIT respectively | Bundled locally; retain notices | Font files add to bundle size |
| Local fixtures and Node test runner | Ranking, testing and demo data | Run on existing hardware | Four origins by three venues in the demo; 6–24 local combinations for 2–8 friends | Demonstration coverage only |
| Leaflet and OpenStreetMap | Interactive pin selection and group map | Leaflet BSD-2-Clause. Standard OSM tiles allow policy-compliant interactive viewing with visible attribution and normal HTTP caching | Nearby places loads the visible map when suggestions exist. Supplementary maps load on request. No prefetch or bulk downloads. No published numeric quota or SLA | Community tile service can restrict access. Review usage before scaling. [Tile policy](https://operations.osmfoundation.org/policies/tiles/) |
| Google Map Tiles API (optional web preview) | Google street map in the Leaflet views | Billing-enabled project. Global 2D tile allowance reviewed November 20, 2026: 100,000 tiles per billing account per month, then US$0.60 per 1,000 in the first paid tier | Restrict the browser key and set the daily tile quota before testing. The allowance is shared across projects. | Opening, panning and zooming can each request multiple tiles. No Google Places or Routes calls. [Google pricing](https://developers.google.com/maps/billing-and-pricing/pricing) |
| HOT Philippine OpenStreetMap POI export | Offline discovery of named meeting venues and bus-terminal proximity | ODbL 1.0 derivative, attribution and downloadable source data included | Zero lookup requests. Coverage reflects the source snapshot. | Openings, closures and travel access need confirmation. [HOT dataset](https://data.humdata.org/dataset/hotosm_phl_points_of_interest) |
| GeoNames | Offline Philippine locality search | CC BY 4.0 dataset with attribution and bundled license | Bundled subset; zero runtime requests | Locality centers are approximate. Arbitrary names and coordinates are accepted worldwide. [Data source](https://www.geonames.org/export/) |
| Expo Location and React Native WebView | Foreground device location and native map display | MIT software, browser geolocation on web, no paid APIs or account | Location requested on user action; browser requires HTTPS or localhost | Permission, device accuracy and network availability vary |
| PostgreSQL and Supabase Data API | Optional shared meetups, invitations and private group origins | Local development runs on existing infrastructure. Hosted use follows the selected project plan. | One roster row, at most one origin and one vote per member. For 2–8 friends and three shortlisted places, up to 6–24 personal trip estimates. A group refresh reads the meetup with its shortlist and votes, its roster, and its origins. Each member can refresh on demand. | Monitor database storage and egress within the free project allowance. On-device planning works independently. |
| LRT-1 rail options | Bundled station coordinates and regular single-journey fares | Wikidata structured coordinates are CC0. Fare values are transcribed from the operator’s published matrix. | Zero runtime requests for the lookup. Review the operator’s effective date when updating the table. | Excludes connecting fares, concessions and live service changes. [LRMC](https://lrmc.ph/our-business-featured/fare-matrix/) · [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing) |
| Ride fare comparisons and external directions | Compare two prices entered by a rider and open the chosen trip in a maps app | Manual price entry runs locally. Google Maps URLs require no API key. | No ride-quote or Google Routes API requests. | Provider prices can change before booking. Angkas publishes business API access; no approved ride-quote access is configured for either provider. [Angkas](https://www.angkas.com/api-solutions) · [Grab](https://developer.grab.com/) · [Maps URLs](https://developers.google.com/maps/documentation/urls/guide) |
| Playwright Core, Chromium and PGlite | Local verification | Open-source local tooling, no cloud test service | Local compute only | Local verification does not certify hosted Supabase or native device behavior |

Distribution fees and store enrollment are outside development scope. No store membership, paid enrollment, billing, or release submission was initiated.
